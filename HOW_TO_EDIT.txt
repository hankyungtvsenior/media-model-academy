K-SENIOR 홈페이지 수정 가이드

1) 일반 문구, 모집정보, 협찬사, 네이버폼 주소는 content.js만 수정하세요.
2) 푸터 로고도 content.js에서 수정할 수 있습니다.

[푸터 로고]
content.js 맨 아래 footer 항목:

footer: {
  message: "여러분의 새로운 도전과 멋진 시작을 응원합니다.",
  wowtvLogo: "assets/sponsors/wowtv-logo.png",
  sfmaLogo: "assets/sponsors/sfma-logo.png"
}

실제 파일은 assets/sponsors/ 폴더에 넣으세요.
- wowtv-logo.png
- sfma-logo.png

PNG, SVG 둘 다 가능하며 실제 파일 확장자와 content.js의 확장자가 같아야 합니다.
예: SVG를 쓴다면 wowtvLogo: "assets/sponsors/wowtv-logo.svg"

[참가신청]
application.applicationUrl 값에 네이버폼 주소를 넣으면 버튼 클릭 시 새 탭으로 이동합니다.
현재 네이버폼 주소가 이미 입력되어 있습니다.

[협찬사]
sponsors 배열에서 name, logo, url을 수정하면 됩니다.
협찬사 로고와 푸터 로고는 서로 별개입니다.

수정 후 index.html을 더블클릭하거나 브라우저에서 새로고침(F5)하여 확인하세요.
GitHub Pages에 반영하려면 수정된 파일과 새 이미지 파일을 GitHub에도 업로드해야 합니다.


[상단 K-SENIOR 로고 교체]
로고 파일은 assets/brand 폴더에 넣으세요.
PNG 권장 원본: 가로 1000px × 세로 240~300px, 투명 배경. SVG도 가능.
content.js의 brand.logo에 경로를 입력하면 상단 텍스트 대신 이미지 로고가 표시됩니다.
예: logo: "assets/brand/k-senior-logo.png",
logo: ""로 두면 기존 텍스트 로고가 계속 표시됩니다.

[ARS 상단 안내바]
시니어 이용자를 고려해 이전 버전보다 약 10% 크게 조정되어 있습니다.
문구와 번호는 content.js의 ars.title, ars.message만 수정하면 됩니다.


[팝업 포스터 바꾸기]
1. assets/popup/ 폴더에 포스터 이미지를 넣습니다.
2. 기본 파일명을 poster.png로 쓰면 추가 수정 없이 표시됩니다.
3. 다른 파일명을 쓰면 content.js의 popup.posterImage를 바꿉니다.
4. 포스터 아래 참가신청 버튼의 이동 주소는 popup.buttonUrl에서 수정합니다.
5. 팝업을 끄려면 popup.enabled를 false로 바꿉니다.


[팝업이 안 보일 때]
- 이번 버전은 이전 팝업의 '오늘 하루 보지 않기' 기록과 분리되어 새로 표시됩니다.
- assets/popup/poster.png가 없거나 경로가 틀리면 텍스트형 팝업으로 자동 대체됩니다.
- 포스터 파일을 GitHub에도 반드시 업로드하세요.
